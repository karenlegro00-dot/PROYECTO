## Recomendaciones de uso

1. Conservar las versiones previas para documentar la evolución del proyecto.
2. Registrar en [Issues](../../issues) los pendientes, avances y verificaciones, con su fecha y responsable cuando se conozcan.
3. Subir cada Word y Excel a la carpeta indicada, sin cambiar su contenido, para facilitar la consulta.
4. Revisar posibles datos personales antes de publicar nuevos archivos: este repositorio es **público**.
5. Mantener separados los dos archivos simulados sobre un proyecto de agua, pues no son evidencia de este proyecto de permanencia estudiantil.

> **Nota:** La clasificación es preliminar y se basa en los documentos suministrados. La grabación institucional de clase no está disponible para verificar instrucciones adicionales del docente.
