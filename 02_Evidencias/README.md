# 02 · Evidencias

**Proyecto:** Programa integral para fortalecer la permanencia estudiantil  
**Estado:** recopilación y verificación documental.

> Esta carpeta contiene fuentes de consulta para fundamentar la formulación. Tener una referencia documental no significa que el programa ya se haya implementado.

## Propósito

Reunir información verificable sobre la permanencia y la deserción en educación superior, así como antecedentes institucionales que permitan delimitar el problema y estudiar las alternativas de intervención.

## Insumos disponibles

### Fuentes documentales

- [Fuentes nuevas identificadas, versión 01](PRO_EDU_SUP_FUENTES_NUEVAS_20261002_v01.docx).

El documento reúne referencias para apoyar el análisis. Las afirmaciones relevantes deben verificarse con sus publicaciones originales y distinguir claramente los datos nacionales de los correspondientes a la universidad.

## Evidencias por obtener

1. Indicadores institucionales actualizados de matrícula, deserción y permanencia.
2. Información verificable sobre servicios de acompañamiento académico, seguimiento y bienestar.
3. Criterios y datos que permitan delimitar la población objetivo.
4. Fuentes y fechas de consulta de las afirmaciones que se incorporen a la ficha y a la matriz.
